# Chill Run 手順書（自分がやる操作）

上から順に進めてください。1〜3 は最初の1回だけです。

---

## 1. 署名の鍵を GitHub に登録する（最初の1回だけ）

「署名の鍵」は、アプリに押すハンコのようなものです。毎回同じハンコで作った APK だけが、
前の版に**上書きインストール**できます（記録が消えません）。鍵は Claude が作って、チャットで次の2つを渡しています。

- `chill-run-release.keystore` … 鍵そのもの（ファイル）
- `GitHubに登録する値.txt` … GitHub に貼り付ける2つの値が書いてあるメモ

### 登録の手順（スマホのブラウザで OK。GitHub アプリではなく Chrome などで開く）

1. Chrome で `https://github.com/taqueriachill-pixel/chill-run/settings/secrets/actions` を開く
   （ログインを求められたらログインする。メニューからたどるなら、リポジトリの **Settings** → **Secrets and variables** → **Actions**）
2. 緑の **New repository secret** を押す
3. 1つ目を登録する
   - **Name**：`SIGNING_KEYSTORE_BASE64`
   - **Secret**：メモの「1つ目の値」を**全部**コピーして貼る（とても長い1行です。途中で切れないように「すべて選択」でコピー）
   - **Add secret** を押す
4. もう一度 **New repository secret** を押して、2つ目を登録する
   - **Name**：`SIGNING_PASSWORD`
   - **Secret**：メモの「2つ目の値」（24文字）
   - **Add secret** を押す
5. 一覧に `SIGNING_KEYSTORE_BASE64` と `SIGNING_PASSWORD` の2つが並んでいれば完了

登録した値は、あとから GitHub の画面で見ることはできません（上書きはできます）。だから次のバックアップが大事です。

## 2. 鍵をバックアップする（最初の1回だけ）

鍵をなくすと、同じハンコを二度と作れません。その場合は新しい鍵で作り直すことになり、
**いったんアプリを消して入れ直す（＝アプリ内の記録が消える）**必要が出ます。

1. `chill-run-release.keystore` と `GitHubに登録する値.txt` の2つを、スマホにダウンロードする
2. **2か所以上**に保存する。例：
   - Google ドライブの、自分しか見られないフォルダ
   - パスワード管理アプリ（メモ欄やファイル添付）、または自宅のパソコン・USB メモリ
3. 人には渡さない。公開のリポジトリにも置かない（このリポジトリには入れていません）

※ この鍵はチャットの中で受け渡しているので、厳密には「チャットの履歴にも残っている」状態です。
自分用のアプリなので実害はほぼありませんが、気になる場合は言ってください。作り直せます（最初のインストール前なら何も失いません）。

## 3. APK を作ってインストールする

1. GitHub で、Claude が作った **Pull request**（「段階1」）を開き、緑の **Merge pull request** → **Confirm merge** を押す
   （これで自動的にビルドが始まります。3〜5分かかります）
2. リポジトリのトップ → 右側（スマホでは下のほう）の **Releases** を開く
3. いちばん新しい `Chill Run 0.1.x` の **Assets** にある `chill-run-0.1.x.apk` をタップしてダウンロード
4. ダウンロードした APK を開く →「この提供元のアプリを許可」を求められたら許可 → **インストール**
5. 次の版からは、同じ手順で新しい APK を入れるだけで上書きされます（記録は残ります）

Releases に何も出ないときは、リポジトリの **Actions** タブを開いて、いちばん上の実行に赤い×が付いていないか見て、Claude に伝えてください。

## 4. 最初に出す許可

アプリを開く → **許可の状態** を開き、上から順にボタンを押します。

| 項目 | 選ぶもの |
|---|---|
| 位置情報 | 「正確」＋「アプリの使用時のみ」 |
| 通知 | 許可 |
| 身体活動 | 許可 |
| 電池の最適化の対象外 | 「許可」 |
| ヘルスコネクト | 「すべて許可」→「許可」。続けて「過去のデータへのアクセス」を聞かれたら、それも許可 |

全部に ✓ が付けば OK です。ボタンを押しても何も出ないときは、いちばん下の「アプリの設定を開く」→「権限」から手で許可します。

AQUOS の「長エネスイッチ」（省エネ）は、走るときはオフにしておいてください。オンだとアプリが止められることがあります。

## 5. 実機チェック（段階1の最初に確かめること）

### 5-1. Zepp と AIfit を、ヘルスコネクトにつなぐ

メニューの名前はアプリの版で少し違うことがあります。見つからないときは、画面の写真を Claude に送ってください。

**Zepp**
1. Zepp を開く → 右下の **プロフィール**
2. **アカウントを追加**（または「サードパーティ連携」）→ **Health Connect（ヘルスコネクト）**
3. 連携をオンにする → 許可の画面では、出てくる項目を全部オンにして構いません（同じランが二重に記録されても気にしない、と決めたため）

**AIfit**
1. AIfit を開く → **マイページ（設定）** → **ヘルスコネクト**（または「データ連携」）
2. 体重・体脂肪率など、出てくる項目を全部オンにする
3. 一度、体組成計に乗って測る（新しいデータを1つ作るため）

### 5-2. PowerBuds の心拍数を1回入れてみる

PowerBuds は、Zepp でワークアウトを始めたときに心拍数を測る作りのようです。確かめるために1回だけ試します。

1. PowerBuds を耳に付ける
2. Zepp で、ウォーキングなどのワークアウトを**5分ほど**記録して終了する
3. Zepp を開いたまま1〜2分待つ（ヘルスコネクトへの書き出しを待つ）

### 5-3. Chill Run で調べる

1. Chill Run → **実機チェック** を開く
2. 「気圧センサー」に ✓ と数字（1000 前後の hPa）が出ているか見る
3. スマホを持って10歩ほど歩き、「数えた歩数」が増えるか見る
4. 「読み上げ」が ✓ か見る（△ や × のときは下の 6 を参照）
5. **ヘルスコネクトの中身を調べる** を押す
6. いちばん下の **結果をコピー** を押して、Claude とのチャットに貼り付ける

この結果で、心拍数をどう取るか（段階4）と、体重などの読み込み（段階6）の作り方を決めます。

## 6. 通信なしで読み上げるための準備

山の中でも声のお知らせが出るように、日本語の音声データをスマホに入れておきます。

1. Chill Run → 実機チェック → **読み上げの設定を開く**
   （または スマホの 設定 → システム → 言語と入力 → テキスト読み上げ）
2. 「優先するエンジン」が **Google の音声サービス**（Speech Recognition & Synthesis）になっているか確認
3. その横の歯車 → **音声データをインストール** → **日本語** → ダウンロード
4. Chill Run の実機チェックを開き直して、「通信なしで使える声」が1個以上になっていれば OK

## 7. 試し走りで見てほしいこと（段階1の確認）

近所を 1.2km 以上、できれば信号待ちを1回はさんで走って（歩いてでも OK）、次を確かめてください。

- [ ] スタートを押すと「スタート」と声が出て、通知が出る
- [ ] 走っている画面のまま電源ボタンで画面を消し、もう一度電源ボタンを押すと、**ロックを解除せずに**走っている画面が出る
- [ ] ポケットに入れて走っても、距離と時間が進み続ける
- [ ] 信号待ちで止まると数秒で「止まっているので時間を止めています」になり、走り出すと戻る
- [ ] 1km で「1キロ。ペース○分○秒。（励まし）」と声が出る。音楽を流していれば、その間だけ音楽が小さくなる
- [ ] 「一時停止」「終了」は、短く押しても動かず、長押しで動く
- [ ] 終了すると記録の画面が開き、距離・タイム・1km ごとの表・ルートの形が出る
- [ ] 記録の画面に「標高：気圧（開始地点の合わせ方：地理院）」と出る
- [ ] 記録の画面の「ヘルスコネクト」が「書き込み済み」になっている
- [ ] 距離が、いつものコースの距離や Zepp などと大きくずれていない（ずれていたら、どのくらいかを教えてください）

別の日に、目標の距離（例：1km）を選んで走り、「あと500メートル」「あと100メートル、ラストスパート！」「目標達成！」が出るかも見てください。

うまくいかなかったことは、「何をしたら、どうなったか」をそのまま書いて送ってください。

## 8. （先にやっても OK）PowerBuds が心拍数を直接流しているかを nRF Connect で見る

段階4の準備です。結果しだいで、走っている最中の心拍数のお知らせができるかが決まります。

1. Play ストアで **nRF Connect for Mobile**（Nordic Semiconductor 製、無料）を入れる
2. PowerBuds を**耳に付ける**（付けていないと心拍センサーが動きません）
3. Zepp で PowerBuds の設定を開き、「心拍数」や「心拍数の共有／常時測定」のような項目があればオンにする
4. nRF Connect を開く → 位置情報と Bluetooth の許可を出す → 右上の **SCAN**
5. 一覧から **Amazfit PowerBuds**（名前が少し違うこともあります）を探し、右の **CONNECT** を押す
   - 見つからない／つながらないときは、Zepp アプリを完全に閉じてからもう一度試す
6. つながると、項目の一覧（サービスの一覧）が出る。その中に **Heart Rate**（`0x180D` と書いてあります）があるか見る
7. あれば、**Heart Rate** をタップ → **Heart Rate Measurement** の右にある「下向き矢印が3つ」のボタンを押す → 数字が流れてくるか見る
8. 「Heart Rate があった／なかった」「数字が流れた／流れなかった」を Claude に伝える（一覧の画面の写真があると確実です）

## 9. 段階2（地図とトレイル）で見てほしいこと

新しい APK（`chill-run-0.2.x.apk`）を、いままでと同じ手順で上書きインストールします。段階1 で記録したランは残ります。

### 9-1. 家の中で確かめられること

- [ ] アプリが普通に開き、前に記録したランが「記録の一覧」に残っている
- [ ] 記録を開くと、**国土地理院の地図**の上にルートが出る（青＝ゆっくり、オレンジ＝速い）。指でずらす、2本指で拡大縮小、右下の ＋／− が効く
- [ ] 1km 以上のランなら、地図の上に 1、2、3… の数字が出る
- [ ] 記録の画面に、標高とペースのグラフが出る
- [ ] 記録の一覧の各行の右に、標高の小さな山の形が出る
- [ ] 設定 → **地図の一時保存** → 地図をずらして生田緑地を真ん中に → 「半径 3km」→ **この範囲を保存する**（Wi-Fi で。数分かかります）
- [ ] 保存のあと、機内モードにして地図を開き、保存した範囲が見られる
- [ ] ホーム → メニュー「インターバル」→ **新しく作る** → 例：ウォームアップなし、走る 0:30、ゆっくり 0:30、2回、クールダウンなし → 保存

### 9-2. 外で確かめること

- [ ] 上で作ったインターバルで走る：スタートで「走る、1本目」、切り替えの前に「3、2、1」、切り替わると振動と声、区間と残り時間が画面に大きく出る
- [ ] 終了後、記録の画面に「インターバルの区間」の表が出る
- [ ] 種類を「トレイル」にして坂のある所を 1km 以上走ると、1km のお知らせに「登り○メートル、下り○メートル」が入る
- [ ] 種類を「ロード」にして生田緑地を走ると、終了後に「トレイルに変えますか？」と聞かれる（聞かれなければ、設定 →「トレイルの判定の目安」の数字を下げて調整できます）
- [ ] 同じルートを2回走ると、2回目の記録に「いつものコース」が出る。「名前を付ける」で「生田緑地」などに変えられる

### 9-3. 知っておいてほしいこと

- 地図を見るには通信が必要です（一度見た場所と、一時保存した範囲は通信なしで見られます）。
- 地図の一時保存は、国土地理院のサーバーに負担をかけないよう、よく走る範囲だけにしてください。
- インターバル中は、止まっても時間は止まりません（休みの時間を正しく数えるため）。
- 「未舗装の道かどうか」を地図から判定する機能は、まだ入れていません（登りの量と急な坂の割合の2つで判定します）。

## 10. 段階3（ボタンで残す）で見てほしいこと

新しい APK（`chill-run-0.3.x.apk`）を上書きインストールします。これまでの記録は残ります。

### 10-1. 最初にやること：許可

Chill Run → **許可の状態** に「マイク」と「カメラ」が増えています。どちらも **許可する** →「アプリの使用時のみ」を選んでください。
**マイクは、走り出す前に許可しておく必要があります**（走っている途中で許可しても、そのランでは録音できません）。

### 10-2. いちばん大事な確認：声を文字にできるか（家の中で OK）

1. Chill Run → **実機チェック** →「声を文字にする」の欄を見る
2. 「日本語のデータが入っていません」と出ていたら、**日本語のデータを入れる** を押し、数分待って画面を開き直す
3. できれば**機内モードにして**から、**5秒話して試す** を押し、「今日は生田緑地を走っています」のように話す
4. 「✓ 文字にできました：「…」」と出るか、「× 文字にできませんでした：…」と出るかを見る
5. いちばん下の **結果をコピー** を押して、Claude に貼る

ここで文字にできなければ、別の音声認識（アプリに組み込むタイプ。アプリが 100MB 前後大きくなります）を提案します。
文字にできなくても、録音そのものは残り、再生できます。

### 10-3. 家の中で確かめられること（足踏みで OK）

スタートを押して、走っている画面で試します。

- [ ] 画面に「メモ」「写真」「動画」の大きなボタンが出ている
- [ ] **メモ**：押すと「ピッ」と振動 → 話す → もう一度押すと「ピッ」と振動で止まる。録音中は「録音中 ○秒」と出る
- [ ] **写真**：押すとカメラの画面になり、3、2、1 のあと自動で撮れて「保存しました」と出て元の画面に戻る。「すぐ撮る」でも撮れる
- [ ] **動画**：同じ流れで、数秒の動画が撮れる（長さは 設定 →「走りながら残す」で 3〜5秒）
- [ ] 画面を消して電源ボタンを押し、**ロックしたまま**メモ・写真・動画ができる
- [ ] 通知の欄を開くと、通知にも「メモ」「写真」「動画」のボタンがある。押して動くか（ロック中に動くかどうかも教えてください）
- [ ] スマホの写真フォルダ（フォトアプリ）に、撮った写真が**入っていない**

※ 足踏みだけで 20m 進まずに終了すると、その記録は保存されません（残したメモや写真も消えます）。確認するときは少し歩いてから終了してください。

### 10-4. 終了したあと

- [ ] 記録の画面の地図に、「声」「写」「動」の丸い印が出ている。押すと開く
- [ ] 「声のメモ」の欄で、自動で文字になる。「再生」で録音が聞ける。「直す」で文字を直せる
- [ ] 「写真・動画」の欄に小さな見本が並び、押すと大きく見られる。写真の向き（縦・横）が合っている
- [ ] 大きく見ている画面の「共有」から、フォトアプリや LINE などに渡せる

## 11. 段階4（心拍数）で見てほしいこと

新しい APK（`chill-run-0.4.x.apk`）を上書きインストールします。これまでの記録は残ります。

### 11-1. 最初の設定（1回だけ）

1. Chill Run → **許可の状態** →「付近のデバイス（Bluetooth）」を許可する（すでに ✓ ならそのまま）
2. **設定** →「心拍数」→ **心拍数の機器を選ぶ・試す**
3. **さがす** を押す → 一覧に **BTALK 2 LITE** が出たら **これを使う**
4. 時計を手首に付けて、時計の側で**走るモード（ランニング）**を始める
5. **つないで試す** を押す → 数字（拍/分）が出れば成功。「試すのをやめる」で止め、時計の走るモードも終了する
6. 設定に戻り、「安静時の心拍数」を入れる（朝、起きてすぐの脈拍が目安。分からなければ 60 のままで OK）
7. 「最大心拍数」は、まず「年齢からの目安」のままで OK

### 11-2. 走るときの流れ

1. **時計で走るモードを始める**（これを忘れると心拍数が届きません）
2. Chill Run のホームで「今日のねらい」を選ぶ
   - **なし**：1km ごとに心拍数とゾーンを伝えるだけ
   - **ゆっくりジョグ**：ゾーン2 が目標。上がりすぎが1分続くと「少しペースを落とそう」
   - **ペース走**：ゾーン3〜4 が目標。上がりすぎと、余裕がありすぎの両方を知らせる
3. スタート。走っている画面に「心拍」と色つきのゾーンが出る

### 11-3. 確かめてほしいこと

- [ ] 走っている画面に心拍数とゾーンが出て、数字が変わっていく
- [ ] 1km のお知らせに「心拍152、ゾーン3」のように入る
- [ ] 「ゆっくりジョグ」で、わざと速く走って1分ほどすると、落とすように言われる。そのあと2分は同じ注意が出ない
- [ ] 時計の走るモードを始め忘れてスタートすると、1分半ほどで「心拍数が届いていません。時計を走るモードにしてください」と言われる
- [ ] 途中で時計の走るモードを始めても、自動でつながって数字が出る
- [ ] 終了後、記録の画面に、平均・最大の心拍数、心拍数のグラフ、ゾーンごとの時間、1km ごとの心拍が出る
- [ ] 心拍数の数字が、体感や時計の表示と大きくずれていない（ずれていたら教えてください）

### 11-4. 知っておいてほしいこと

- **心拍ゾーンはトレーニングの目安です。体調や病気の判断に使うものではありません。**
- **胸の痛み、強い息切れ、めまい、ふらつきがあれば、数字に関係なくすぐに止まって休んでください。**
- 年齢からの最大心拍数の目安（208 − 0.7 × 年齢）は、人によって大きくずれることがあります。
  いつもの走りで「ゾーンが体感と合わない」と感じたら、設定で最大心拍数や安静時心拍数を直してください。
- 手首で測る心拍数は、走っている最中は腕の振りや汗でずれることがあります。時計は手首の骨より少し上に、ややきつめに付けると安定します。
- 時計を使わない日は、あとから「ヘルスコネクトから心拍数を取り込む」（記録の画面の下のほう）も使えます。
  ただし、Zepp などがその時間帯の心拍数をヘルスコネクトに書いている場合だけです。

## 12. 段階5（音楽）で見てほしいこと

新しい APK（`chill-run-0.5.x.apk`）を上書きインストールします。これまでの記録は残ります。

### 12-1. 準備（家の中で）

使えるのは、**スマホの中にファイルとして入っている自分の曲**（MP3・AAC・FLAC など）だけです。
Spotify や YouTube Music などの配信の曲は使えません（ほかのアプリの音は、速さを変えられないため）。

1. 曲のファイルを、スマホの「Music」フォルダなど、1つのフォルダにまとめておく（中にフォルダが分かれていても OK）
2. Chill Run のホーム →「音楽」→ **曲とテンポの設定**
3. **フォルダを選ぶ** → 曲のフォルダを開いて、下の「このフォルダを使用」→「許可」
4. 曲が見つかると、テンポ（BPM）を1曲ずつ自動で調べ始める（1曲に数秒。画面を開いたまま待つ）
5. 「BPM の一覧」に数字が並ぶ

### 12-2. BPM が合っているかを見る

自動で調べた BPM は、曲によっては外れます（静かな曲、リズムがはっきりしない曲、途中でテンポが変わる曲は苦手です）。

- [ ] 知っている曲を2〜3曲選んで、数字が体感と合っているか見る
- [ ] 違っていたら、曲を押す → **曲を流す** → 拍に合わせて **ここをタップ**（4回以上）→ **この BPM にする**
- [ ] 倍や半分の数字（170 のはずが 85 など）は、そのままで大丈夫（同じテンポとして扱います）
- [ ] ランで使いたくない曲は、右のスイッチをオフにする

### 12-3. 走って確かめること

1. ホームの「音楽を流す」をオンにしてスタート（Bluetooth のイヤホンをつないでおく）

- [ ] 走り出すと曲が流れる
- [ ] 走っている画面に、曲名と「曲 ○○BPM・速さ ○○%・目標 ○○」が出る
- [ ] ペースを上げ下げすると、数秒かけて曲の速さが変わる（音の高さは変わらない）
- [ ] 曲の終わりで、次の曲が重なりながら切り替わる
- [ ] 声のお知らせの間、音楽が小さくなり、終わると戻る
- [ ] 画面の「止める」「次の曲」が効く。イヤホンのボタン（再生・停止、次の曲）でも操作できる
- [ ] インターバルで、「走る」と「ゆっくり」が切り替わると、曲も切り替わる
- [ ] 速さを変えた曲が、聞いていて気持ち悪くないか（気になるなら、音楽の設定で「速さを変える幅」をせまくできます）

### 12-4. 設定の意味

- **いまの足に合わせる**：直近20秒ほどの歩数に、曲のテンポを合わせます。
- **目標のペースに引っ張る**：決めたペースに合うテンポで流します。遅れているときは、曲を少し速めにします。
  ペースとテンポの関係は、最初は一般的な目安で、1km の記録が 8個以上たまると自分の記録から学びます。
- **速さを変える幅**：初期は ±10%。この幅に収まる曲の中から選びます。収まる曲がないときは、いちばん近い曲を流し、画面に「合う曲がないので近い曲」と出ます。

## 13. 段階6（ランムービーとふりかえり）で見てほしいこと

新しい APK（`chill-run-0.6.x.apk`）を上書きインストールします。これまでの記録は残ります。

### 13-1. ランムービー（家の中で OK。前に記録したランで試せます）

- [ ] 記録の一覧 → ランを開く →「今日のランムービー」→ **ランムービーを作る**（30秒〜1分。画面は開いたまま）
- [ ] できたら **見る・共有する** で再生できる（約10秒、縦長、音なし）

- [ ] アプリの中の記録の画面の地図では、これまでどおり全部見える

※ SNS に出す前に、ムービーに自宅のまわりが映っていないかを、一度は目で確かめてください。

### 13-3. ふりかえり

### 13-5. バックアップ（大事）

## 14. ランムービーの曲（その場で作る音楽）

新しい APK（`chill-run-0.6.x.apk` の新しい版）を上書きインストールします。

### 14-1. どう決まるか

曲は、既存の曲を使わず、アプリがその場で作ります。「作り直す」たびに別の曲になります。
曲の型は4つあり、それぞれ本物のジャンルの「お決まり」（テンポ、ドラムの打ち方、和音の種類）に沿って作ります。

| 型 | テンポ | どんな曲か |
|---|---|---|
| ローファイ・ヒップホップ | 70〜86 | はねたリズム、ゆるいキックとスネア、丸いエレピのジャズ和音、レコードのぱちぱち音、こもった音 |
| ジャジー（スウィング） | 96〜114 | 「チーン、チッチ」のライドシンバル、歩くようなウッドベース、ピアノの合いの手、ビブラフォン |
| ディープハウス | 120〜126 | 4つ打ちのキック、2・4拍のクラップ、裏拍のハイハット、短い和音の「ひと突き」、キックに合わせて音がうねる |
| クラブ（メロディック・テクノ） | 122〜128 | 細かく刻む分散和音、裏拍のベース、広がる和音、盛り上げのノイズ |

どの型になるかは、ランの内容でくじの当たりやすさが変わります（同じ内容でも、ときどき別の型が出ます）。

| 材料 | どこから | 曲への効き方 |
|---|---|---|
| ロードかトレイルか | ランの種類 | ロード＝ハウス・クラブが出やすい／トレイル＝ジャジー・ローファイが出やすい |
| つらかったか、楽しかったか | 記録の画面の「今日の体調」。付けていなければ、ひとことメモと声のメモの言葉（「きつい」「楽しい」など） | 楽しい＝明るい響きで、踊れる型が出やすい／つらい＝しっとりした響きで、ローファイが出やすく、音数が少なめ |
| 晴れか、雨か | 天気を自動で調べる（手でも選べる） | 晴れ＝明るい響き、ハウスが出やすい／雨＝ローファイが出やすく、雨音を重ねる |
| 寒いか、暑いか | 気温を自動で調べる（手でも選べる） | 寒い（10℃ 未満）・雪＝澄んだビブラフォン、響き多め、少し速め／暑い（26℃ 以上）＝こもらせて、ゆったり |
| がんばり具合 | 心拍数（ゾーン4 以上にいた割合） | がんばったランほど、クラブが出やすく、テンポも速め |

### 14-2. 試し方

1. 記録を開く →「今日の体調」を選ぶ（例：絶好調）
2. 「今日のランムービー」の欄で、天気と気温を確かめる（「分からない」のままでも作れます。外れていたら、下の「晴れ・くもり・雨・雪」「寒い・ちょうどいい・暑い」で直す）
3. **ランムービーを作る**（または **作り直す**）
4. 「見る・共有する」で聞く。欄に「いまの曲：ロード・楽しかった・晴れ → ディープハウス、明るい響き（メジャー7th・9th）、テンポ 124」のように、どう決めたかが出る

- [ ] 曲が入っている
- [ ] 体調を「つらい」に変えて作り直すと、雰囲気が変わる（ローファイやジャジーが多くなる）
- [ ] 何回か作り直すと、ちがう型の曲も出てくる
- [ ] イヤホンで聞くと、左右に広がって聞こえる（ステレオ）
- [ ] 主旋律がずっと鳴っていない（区切りに短い合いの手が入るだけ）
- [ ] 天気を「雨」にして作り直すと、雨音が入る
- [ ] 同じ設定で作り直しても、毎回ちがう曲になる
- [ ] 曲を入れたくないときは、設定 →「ランムービーと、隠す場所」→「その場で作った曲を入れる」をオフ

### 14-3. 知っておいてほしいこと

- 天気と気温は、Open-Meteo という無料の天気サービスで調べます。送るのは、約1km 単位に丸めた位置と日付だけです。
  通信がないときは「分からない」のままになり、天気ぬきで曲を作ります。
- 自動で調べた天気は、その時間のおおよその予報・観測なので、実際と違うことがあります。違っていたら手で直してください。
- 曲は決まりごとで組み立てて、音もアプリの中で合成しています。本物の楽器の録音ではないので、音色には限りがあります。「この型をもっとこうしたい」「この型は要らない」があれば教えてください。
