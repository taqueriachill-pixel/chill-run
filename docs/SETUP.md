# Chill Run 手順書（自分がやる操作）

上から順に進めてください。1〜3 は最初の1回だけです。

---

## 1. 署名の鍵を GitHub に登録する（最初の1回だけ）

「署名の鍵」は、アプリに押すハンコのようなものです。毎回同じハンコで作った APK だけが、
前の版に**上書きインストール**できます（記録が消えません）。鍵は Claude が作って、チャットで次の2つを渡しています。

- `chill-run-release.keystore` … 鍵そのもの（ファイル）
- `GitHubに登録する値.txt` … GitHub に貼り付ける2つの値が書いてあるメモ

### 登録の手順（スマホのブラウザで OK。GitHub アプリではなく Chrome などで開く）

1. Chrome で `https://github.com/taqueriachill-pixel/chill-run/settings/secrets/actions` を開く
   （ログインを求められたらログインする。メニューからたどるなら、リポジトリの **Settings** → **Secrets and variables** → **Actions**）
2. 緑の **New repository secret** を押す
3. 1つ目を登録する
   - **Name**：`SIGNING_KEYSTORE_BASE64`
   - **Secret**：メモの「1つ目の値」を**全部**コピーして貼る（とても長い1行です。途中で切れないように「すべて選択」でコピー）
   - **Add secret** を押す
4. もう一度 **New repository secret** を押して、2つ目を登録する
   - **Name**：`SIGNING_PASSWORD`
   - **Secret**：メモの「2つ目の値」（24文字）
   - **Add secret** を押す
5. 一覧に `SIGNING_KEYSTORE_BASE64` と `SIGNING_PASSWORD` の2つが並んでいれば完了

登録した値は、あとから GitHub の画面で見ることはできません（上書きはできます）。だから次のバックアップが大事です。

## 2. 鍵をバックアップする（最初の1回だけ）

鍵をなくすと、同じハンコを二度と作れません。その場合は新しい鍵で作り直すことになり、
**いったんアプリを消して入れ直す（＝アプリ内の記録が消える）**必要が出ます。

1. `chill-run-release.keystore` と `GitHubに登録する値.txt` の2つを、スマホにダウンロードする
2. **2か所以上**に保存する。例：
   - Google ドライブの、自分しか見られないフォルダ
   - パスワード管理アプリ（メモ欄やファイル添付）、または自宅のパソコン・USB メモリ
3. 人には渡さない。公開のリポジトリにも置かない（このリポジトリには入れていません）

※ この鍵はチャットの中で受け渡しているので、厳密には「チャットの履歴にも残っている」状態です。
自分用のアプリなので実害はほぼありませんが、気になる場合は言ってください。作り直せます（最初のインストール前なら何も失いません）。

## 3. APK を作ってインストールする

1. GitHub で、Claude が作った **Pull request**（「段階1」）を開き、緑の **Merge pull request** → **Confirm merge** を押す
   （これで自動的にビルドが始まります。3〜5分かかります）
2. リポジトリのトップ → 右側（スマホでは下のほう）の **Releases** を開く
3. いちばん新しい `Chill Run 0.1.x` の **Assets** にある `chill-run-0.1.x.apk` をタップしてダウンロード
4. ダウンロードした APK を開く →「この提供元のアプリを許可」を求められたら許可 → **インストール**
5. 次の版からは、同じ手順で新しい APK を入れるだけで上書きされます（記録は残ります）

Releases に何も出ないときは、リポジトリの **Actions** タブを開いて、いちばん上の実行に赤い×が付いていないか見て、Claude に伝えてください。

## 4. 最初に出す許可

アプリを開く → **許可の状態** を開き、上から順にボタンを押します。

| 項目 | 選ぶもの |
|---|---|
| 位置情報 | 「正確」＋「アプリの使用時のみ」 |
| 通知 | 許可 |
| 身体活動 | 許可 |
| 電池の最適化の対象外 | 「許可」 |
| ヘルスコネクト | 「すべて許可」→「許可」。続けて「過去のデータへのアクセス」を聞かれたら、それも許可 |

全部に ✓ が付けば OK です。ボタンを押しても何も出ないときは、いちばん下の「アプリの設定を開く」→「権限」から手で許可します。

AQUOS の「長エネスイッチ」（省エネ）は、走るときはオフにしておいてください。オンだとアプリが止められることがあります。

## 5. 実機チェック（段階1の最初に確かめること）

### 5-1. Zepp と AIfit を、ヘルスコネクトにつなぐ

メニューの名前はアプリの版で少し違うことがあります。見つからないときは、画面の写真を Claude に送ってください。

**Zepp**
1. Zepp を開く → 右下の **プロフィール**
2. **アカウントを追加**（または「サードパーティ連携」）→ **Health Connect（ヘルスコネクト）**
3. 連携をオンにする → 許可の画面では、出てくる項目を全部オンにして構いません（同じランが二重に記録されても気にしない、と決めたため）

**AIfit**
1. AIfit を開く → **マイページ（設定）** → **ヘルスコネクト**（または「データ連携」）
2. 体重・体脂肪率など、出てくる項目を全部オンにする
3. 一度、体組成計に乗って測る（新しいデータを1つ作るため）

### 5-2. PowerBuds の心拍数を1回入れてみる

PowerBuds は、Zepp でワークアウトを始めたときに心拍数を測る作りのようです。確かめるために1回だけ試します。

1. PowerBuds を耳に付ける
2. Zepp で、ウォーキングなどのワークアウトを**5分ほど**記録して終了する
3. Zepp を開いたまま1〜2分待つ（ヘルスコネクトへの書き出しを待つ）

### 5-3. Chill Run で調べる

1. Chill Run → **実機チェック** を開く
2. 「気圧センサー」に ✓ と数字（1000 前後の hPa）が出ているか見る
3. スマホを持って10歩ほど歩き、「数えた歩数」が増えるか見る
4. 「読み上げ」が ✓ か見る（△ や × のときは下の 6 を参照）
5. **ヘルスコネクトの中身を調べる** を押す
6. いちばん下の **結果をコピー** を押して、Claude とのチャットに貼り付ける

この結果で、心拍数をどう取るか（段階4）と、体重などの読み込み（段階6）の作り方を決めます。

## 6. 通信なしで読み上げるための準備

山の中でも声のお知らせが出るように、日本語の音声データをスマホに入れておきます。

1. Chill Run → 実機チェック → **読み上げの設定を開く**
   （または スマホの 設定 → システム → 言語と入力 → テキスト読み上げ）
2. 「優先するエンジン」が **Google の音声サービス**（Speech Recognition & Synthesis）になっているか確認
3. その横の歯車 → **音声データをインストール** → **日本語** → ダウンロード
4. Chill Run の実機チェックを開き直して、「通信なしで使える声」が1個以上になっていれば OK

## 7. 試し走りで見てほしいこと（段階1の確認）

近所を 1.2km 以上、できれば信号待ちを1回はさんで走って（歩いてでも OK）、次を確かめてください。

- [ ] スタートを押すと「スタート」と声が出て、通知が出る
- [ ] 走っている画面のまま電源ボタンで画面を消し、もう一度電源ボタンを押すと、**ロックを解除せずに**走っている画面が出る
- [ ] ポケットに入れて走っても、距離と時間が進み続ける
- [ ] 信号待ちで止まると数秒で「止まっているので時間を止めています」になり、走り出すと戻る
- [ ] 1km で「1キロ。ペース○分○秒。（励まし）」と声が出る。音楽を流していれば、その間だけ音楽が小さくなる
- [ ] 「一時停止」「終了」は、短く押しても動かず、長押しで動く
- [ ] 終了すると記録の画面が開き、距離・タイム・1km ごとの表・ルートの形が出る
- [ ] 記録の画面に「標高：気圧（開始地点の合わせ方：地理院）」と出る
- [ ] 記録の画面の「ヘルスコネクト」が「書き込み済み」になっている
- [ ] 距離が、いつものコースの距離や Zepp などと大きくずれていない（ずれていたら、どのくらいかを教えてください）

別の日に、目標の距離（例：1km）を選んで走り、「あと500メートル」「あと100メートル、ラストスパート！」「目標達成！」が出るかも見てください。

うまくいかなかったことは、「何をしたら、どうなったか」をそのまま書いて送ってください。

## 8. （先にやっても OK）PowerBuds が心拍数を直接流しているかを nRF Connect で見る

段階4の準備です。結果しだいで、走っている最中の心拍数のお知らせができるかが決まります。

1. Play ストアで **nRF Connect for Mobile**（Nordic Semiconductor 製、無料）を入れる
2. PowerBuds を**耳に付ける**（付けていないと心拍センサーが動きません）
3. Zepp で PowerBuds の設定を開き、「心拍数」や「心拍数の共有／常時測定」のような項目があればオンにする
4. nRF Connect を開く → 位置情報と Bluetooth の許可を出す → 右上の **SCAN**
5. 一覧から **Amazfit PowerBuds**（名前が少し違うこともあります）を探し、右の **CONNECT** を押す
   - 見つからない／つながらないときは、Zepp アプリを完全に閉じてからもう一度試す
6. つながると、項目の一覧（サービスの一覧）が出る。その中に **Heart Rate**（`0x180D` と書いてあります）があるか見る
7. あれば、**Heart Rate** をタップ → **Heart Rate Measurement** の右にある「下向き矢印が3つ」のボタンを押す → 数字が流れてくるか見る
8. 「Heart Rate があった／なかった」「数字が流れた／流れなかった」を Claude に伝える（一覧の画面の写真があると確実です）

## 9. 段階2（地図とトレイル）で見てほしいこと

新しい APK（`chill-run-0.2.x.apk`）を、いままでと同じ手順で上書きインストールします。段階1 で記録したランは残ります。

### 9-1. 家の中で確かめられること

- [ ] アプリが普通に開き、前に記録したランが「記録の一覧」に残っている
- [ ] 記録を開くと、**国土地理院の地図**の上にルートが出る（青＝ゆっくり、オレンジ＝速い）。指でずらす、2本指で拡大縮小、右下の ＋／− が効く
- [ ] 1km 以上のランなら、地図の上に 1、2、3… の数字が出る
- [ ] 記録の画面に、標高とペースのグラフが出る
- [ ] 記録の一覧の各行の右に、標高の小さな山の形が出る
- [ ] 設定 → **地図の一時保存** → 地図をずらして生田緑地を真ん中に → 「半径 3km」→ **この範囲を保存する**（Wi-Fi で。数分かかります）
- [ ] 保存のあと、機内モードにして地図を開き、保存した範囲が見られる
- [ ] ホーム → メニュー「インターバル」→ **新しく作る** → 例：ウォームアップなし、走る 0:30、ゆっくり 0:30、2回、クールダウンなし → 保存

### 9-2. 外で確かめること

- [ ] 上で作ったインターバルで走る：スタートで「走る、1本目」、切り替えの前に「3、2、1」、切り替わると振動と声、区間と残り時間が画面に大きく出る
- [ ] 終了後、記録の画面に「インターバルの区間」の表が出る
- [ ] 種類を「トレイル」にして坂のある所を 1km 以上走ると、1km のお知らせに「登り○メートル、下り○メートル」が入る
- [ ] 種類を「ロード」にして生田緑地を走ると、終了後に「トレイルに変えますか？」と聞かれる（聞かれなければ、設定 →「トレイルの判定の目安」の数字を下げて調整できます）
- [ ] 同じルートを2回走ると、2回目の記録に「いつものコース」が出る。「名前を付ける」で「生田緑地」などに変えられる

### 9-3. 知っておいてほしいこと

- 地図を見るには通信が必要です（一度見た場所と、一時保存した範囲は通信なしで見られます）。
- 地図の一時保存は、国土地理院のサーバーに負担をかけないよう、よく走る範囲だけにしてください。
- インターバル中は、止まっても時間は止まりません（休みの時間を正しく数えるため）。
- 「未舗装の道かどうか」を地図から判定する機能は、まだ入れていません（登りの量と急な坂の割合の2つで判定します）。
