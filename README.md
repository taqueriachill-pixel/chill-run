# Chill Run：Claude Code への依頼一式

自分専用のランニング記録アプリ（Android）。仕様は `docs/SPEC.md`。

## Claude Code に最初に送るお願い文

```
このリポジトリにあるランニングアプリの依頼一式をもとに、Androidアプリを作ってください。

まず README.md と docs/SPEC.md を読んでください。仕様の中で、Android 16 では実現が難しい点や、もっと良い方法がある点があれば、作り始める前に教えてください。

【前提】
- 私はプログラミング未経験です。説明はすべて日本語で、専門用語はかみくだいてください。
- スマホは AQUOS R8 pro（Android 16）です。必要な許可は全部出します。
- 以前、同じ進め方で音楽プレイヤーや時計などのアプリを作りました。ビルドは GitHub Actions、APK は GitHub の Releases に置いてください。
- APK の署名の鍵は固定してください。鍵の作り方、GitHub への登録方法、バックアップ方法も教えてください。
- 私がやる必要のある操作（許可の出し方、ヘルスコネクトや Zepp の設定、nRF Connect での確認など）は、1手順ずつ具体的に教えてください。

【進め方】
- docs/SPEC.md の「11. 作る順番」のとおり、段階ごとに APK を作ってください。私が実機で確認したら次へ進みます。
- 段階が終わるごとに、決めたことと次にやることを docs/PROGRESS.md に書き足してください（会話が長くなっても、ここを読めば続きから再開できるように）。
- まずは段階1から始めてください。
```
